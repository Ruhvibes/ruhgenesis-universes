# 🌌 RuhGenesis Community Universes

Player-published universes for **RuhGenesis — The Living Universe** by Hasnain Khan.

## How publishing works
1. In the RuhGenesis app, tap **Publish Universe**.
2. Your browser opens with a pre-filled GitHub issue — just tap **Submit**.
3. A bot validates your universe and adds it to `universes.json` automatically.
4. It appears in everyone's **Explore Global Universe** list!

No API keys, no servers — just GitHub.
